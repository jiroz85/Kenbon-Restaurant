# 🍽️ Kenbon Restaurant

A full-stack restaurant management system designed to help restaurant staff manage orders, menus, inventory, and kitchen operations through a centralized web application.

## ✨ Features

- 🔐 User authentication with JWT
- 👥 Role-based access for restaurant staff
- 📊 Dashboard with sales and operational summaries
- 🧾 Order management and POS workflow
- 🍽️ Menu and catalog management
- 📦 Inventory management
- 👨‍🍳 Kitchen Display System (KDS)
- 🔄 Order status tracking
- 🛡️ Protected routes and authenticated API requests
- 📱 Responsive staff management interface

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- TypeScript
- Tailwind CSS
- Axios
- React Router

### Backend

- Node.js
- TypeScript
- REST API
- JWT Authentication

## 🏗️ Application Areas

### Staff / Admin App

Used by administrators, managers, waiters, cashiers, and kitchen staff to manage daily restaurant operations.

### Kitchen Display System

Provides a dedicated workflow for kitchen staff to view orders and update their preparation status.

### Customer Interface

Planned for a future phase to allow customers to browse the menu, place orders, and track order status.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Clone the repository

```bash
git clone https://github.com/jiroz85/Kenbon-Restaurant.git
cd Kenbon-Restaurant
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```
